Monochrome presentation variants of the original SVGs in the parent directory.

Path geometry, view boxes, and source attribution are unchanged. Only paint colours have been adjusted; white counterforms are preserved, JavaScript lettering is reversed for contrast, and scikit-learn retains grey overlapping shapes to keep its lettering legible. The active page embeds these shapes as inline SVG symbols with explicit theme colours; it does not invert images in dark mode. See the parent source manifests and licences for attribution.
